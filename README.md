# Content Calendar — Glassmorphic UI + GSAP Sliding Pill Motion

Fully integrated **V1 Supabase Content Calendar** upgraded with the **Glassmorphic UI**, **Custom Light & Dark Ribbon Wallpapers** (`assets/bg-light.webp` & `assets/bg-dark.jpg`), and **GSAP Sliding Pill Motion** across all navigation bars, view switchers, and platform tabs.

## Key Features
- **GSAP Sliding Pill Transitions**: Smooth `power3.out` pill animations across the admin sidebar (`Post today`, `Calendar`, `Week`, `List`, `Board`, `Feed`, `Year`, `Insights`, `Media`, `Report`, `All clients`), view switchers, feed platform tabs, and client view bars.
- **Glassmorphic Light & Dark Theme**: Frosted glass workspace panels (`backdrop-filter: blur(24px)`) layered over your custom light and dark ribbon backgrounds, switchable anytime via the `◐` header button.
- **Full V1 Supabase Functionality**: Admin & Client portals, post approvals, Kanban Board view, Excel & Meta CSV imports, Google Drive media uploads, Insights charts, Ideas Bank, and PWA push notifications.

## Deploying to GitHub Pages
1. Extract `content-calendar-gsap-glassmorphic.zip` into the root of your GitHub repository.
2. Push to `main`—GitHub Pages will serve the updated calendar automatically.
