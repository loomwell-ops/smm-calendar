# Murnova Social Media Calendar (Fixed Build)

This build fixes the JavaScript syntax error in `index.html` that prevented the calendar grid, navigation pills, and Supabase login/data sync from executing.

## How to Deploy on GitHub Pages
1. Extract `murnova-calendar-fixed.zip` into the root folder of your GitHub repository (replacing the previous `index.html`).
2. Commit and push to `main`.
3. Hard-refresh your GitHub Pages URL (`Ctrl+Shift+R` or `Cmd+Shift+R`).
