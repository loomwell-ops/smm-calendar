# LoomWellOps — Dark Mode Default V2 Build

This build configures **LoomWellOps** to always launch in **Dark Mode** by default (with the dark ribbon wallpaper and frosted obsidian glass shell), while keeping the sun/moon toggle button available in the top bar.

## Deploying to GitHub Pages
1. Extract `loomwellops-v2-darkmode.zip` into the root of your GitHub repository.
2. Push all files (`index.html`, `style.css`, `manifest.webmanifest`, `branding.json`, `assets/`, and icons) to `main`.
3. Hard-refresh (`Ctrl+Shift+R` or `Cmd+Shift+R`) on your live GitHub Pages URL.
